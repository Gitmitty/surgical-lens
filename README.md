# Surgical Lens

The photography of **Carl Morel**.

**[View the live site →](https://gitmitty.github.io/surgical-lens/)**



## About

Carl Morel is a photographer focused on portraits and people.

> "I started shooting because I was curious about people, what they carry, how they move through the world, what a single frame can say about someone."

Carl studies Biology at Berea College (B.A., 2023–2027) and works as a Teaching Assistant in the Biology Department (2024–2027).

## About this site

Surgical Lens is a single-page, editorial photography portfolio built to let the work speak for itself: large images, deliberate whitespace, minimal text, and a sequence rather than a grid. It's organized in two chapters (community and portraiture) bookended by a hero image and a closing frame, with a full archive and a lightbox viewer.

## Built with

Plain HTML, CSS, and JavaScript. No frameworks, no build step, no external dependencies beyond two Google Fonts (Bodoni Moda and Archivo). Every photograph is embedded directly in the single HTML file, so the entire site is one file that works anywhere, with nothing that can go missing.

## Running it locally

Download `index.html` and open it in any browser. That's the whole setup.
